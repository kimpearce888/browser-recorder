# browser-recorder

> Early prototype shell for a browser workflow recorder.
> **Superseded by [browser-tutorial-recorder](https://github.com/kimpearce888/browser-tutorial-recorder).**

This repository was the first spike at recording browser interactions
(clicks, scrolls, navigations, form fills) back in September 2026.
The recording engine was then rewritten from scratch with a far more
robust architecture — smart step descriptions, on-image click markers,
a 9-tool annotation editor, destructive blur/redaction, and 7 export
formats — and released as **browser-tutorial-recorder**:

- **Repo:** https://github.com/kimpearce888/browser-tutorial-recorder
- **What it does:** turn any browser workflow into a polished,
  shareable step-by-step tutorial (HTML / PDF / Markdown / GIF / PNG /
  JSON / text), entirely on-device — no accounts, no cloud uploads,
  no telemetry.

Kept for history. No further development will happen here.
